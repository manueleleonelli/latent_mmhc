This is the supporting code to the paper "Modeling Psychological Profiles in Volleyball via Mixed-Type Bayesian Networks" (arXiv:2509.22111). The most relevant files are:

- 'utils.R' which contain utility functions for the learning algorithms;
- 'learning_algs.R' implementing all routines introduced in the paper for learning Bayesian networks for mixed data;
- 'volley.net' the learned Bayesian network which can be opened in R with bnlearn or directly with the GeNie software.
